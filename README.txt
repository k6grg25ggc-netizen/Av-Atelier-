AV Atelier Team Edition

Included:
- Team overview
- Daily work notes
- Equipment issues and troubleshooting
- Announcements
- Event setup and teardown checklist records
- Edit/delete controls
- Local browser storage

Important:
This is a working front-end prototype. Data is stored only in the current browser/device.
For real shared access across 2-5 people, connect the app to a hosted database/authentication
service such as Supabase or Firebase. GitHub Pages can host the front end but does not itself
provide shared synchronized team storage.
